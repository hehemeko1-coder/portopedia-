# Portopedia

Portopedia is a creator portfolio platform. This repository is being built against the supplied Portopedia PRD and Master AI Engineering Prompt.

## Product direction

The supplied PRD establishes a responsive, accessible, SEO-friendly, installable creator portfolio platform with a playful brutalist visual direction, light and dark themes, secure authentication, portfolio publishing, media uploads, and ownership-aware permissions. The engineering prompt defines the required architecture and delivery standards.

## Technology

- Web: Next.js, React, TypeScript, Tailwind CSS, PWA
- API: Node.js, Express, TypeScript, versioned REST
- Data: PostgreSQL and Prisma
- Object storage: Cloudflare R2
- Authentication: email/password and Google OAuth
- Email delivery: Brevo
- Hosting: Render

## Repository status

The repository is being initialized from an empty GitHub repository. Feature implementation will be delivered in verifiable increments. Provider credentials and production service configuration must be supplied through environment variables; no credentials belong in source control.

## Local development

Setup instructions will be expanded alongside the application packages. See `docs/` for architecture, API, database, security, and deployment documentation as those components are added.
